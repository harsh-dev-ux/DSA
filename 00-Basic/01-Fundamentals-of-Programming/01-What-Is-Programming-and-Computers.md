# What Is Programming and What Are Computers?

A computer is basically a machine that follows instructions. It's super fast and obedient but has zero common sense — it does exactly what you tell it, nothing more nothing less. If your instructions are wrong, the output is wrong.

**Hardware** = physical stuff you can touch (keyboard, monitor, CPU)
**Software** = the apps and programs running on it (WhatsApp, games, Windows)

The three main parts that matter:
- **CPU** — the brain, does all the thinking and processing
- **RAM** — temporary memory, like a desk where you keep stuff you're currently working on. Clears when you shut down
- **Storage** (HDD/SSD) — permanent memory, where files actually stay saved

A **program** is just a set of instructions telling the computer what to do. Every app you use — calculator, Instagram, even traffic lights — is a program someone wrote.

A **bug** is when those instructions have a mistake and something goes wrong. **Debugging** = finding and fixing those mistakes.

Computers only understand binary (0s and 1s) which is impossible for us to write directly, so we use **programming languages** (Python, C++, Java, etc.) that act as a translator between us and the machine.
